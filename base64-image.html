How to use Base64 to Image

Preview image data encoded as a Base64 string or data URL and download the decoded image. The input must contain valid image data; Base64 is encoding, not encryption.

  1. Paste a complete image data URL or a Base64 string, then choose Preview image.
  2. If decoding succeeds, check the preview and select Download image.
  3. Only use data you trust and avoid entering sensitive content on shared devices.

About the Base64 to Image

This tool turns Base64 image data back into a picture you can preview and download. It helps when an API, database or email gives you an image as a long text string.

Tips for best results

  • Paste only the Base64 part, or the full data URL if the tool accepts it.
  • If the image does not show, check that the string is complete and was not cut off.

Common questions about this tool

What image types can Base64 hold?

Common formats such as PNG, JPG, GIF and WebP can all be stored as Base64.

Why is my Base64 string so long?

Base64 makes data about one third larger than the original file, so even small images give long strings.
