How to use Text Cleaner

Clean copied text by trimming line edges, collapsing repeated spaces and removing blank lines. This can help tidy text pasted from documents, websites or spreadsheets.

  1. Paste the text you want to clean.
  2. Select which cleanup options to apply, then choose Clean text.
  3. Review the result before copying it; cleanup changes formatting and whitespace, not the meaning of the words.
