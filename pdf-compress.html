Compress PDF Files Online for Free

Reduce the size of image-heavy or scanned PDF files using an adjustable image-quality setting. Processing happens in your browser. Note that pages are converted to images, so selectable text and some document features may not be preserved.

How to use this tool

  1. Select your PDF file using the file picker above.
  2. Choose the tool's action button and wait for processing to finish.
  3. Download the result and check that it meets your needs.

Frequently asked questions

How do I compress a PDF online?

Choose a PDF, adjust the quality slider, and click Compress PDF. The compressed file downloads when processing finishes.

Will compression always make my PDF smaller?

Not always. Results depend on the original PDF and the quality setting; compare the original and output file sizes.

Will searchable text be preserved?

This tool rebuilds pages as images, so selectable text, links, forms, and some accessibility features may not be preserved.
